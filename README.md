# HydroVolt Mining – Website

Statische Website (HTML/CSS/JS, ohne Build-Schritt) für **HydroVolt Mining** –
Bitcoin-Mining mit 100 % Wasserkraft aus dem Itaipú-Staudamm in Paraguay.

## Seiten

| Datei | Inhalt |
|-------|--------|
| `index.html` | Landingpage: Hero, Live-Marktdaten, **Warum Paraguay** (inkl. Strompreis-Vergleich), Tarife, ROI-Rechner, Hardware, Service, Ablauf, Sicherheit, Testimonials, FAQ, Kontakt |
| `impressum.html` | Anbieterkennzeichnung (§ 5 DDG) |
| `datenschutz.html` | Datenschutzerklärung (DSGVO) |
| `agb.html` | Allgemeine Geschäftsbedingungen |
| `risikohinweis.html` | Risikohinweis zum Mining |
| `widerruf.html` | Widerrufsbelehrung + Muster-Formular |
| `legal.css` | Gemeinsames Stylesheet der Rechtsseiten |

## Lokal ansehen

Einfach `index.html` im Browser öffnen – kein Server nötig.
(Für die Live-Kursdaten der externen APIs wird eine Internetverbindung benötigt.)

## ⚠️ Vor dem Livegang ausfüllen

Die Rechtsseiten enthalten gelb markierte Platzhalter `[…]`. Diese müssen durch die
**rechtsverbindlichen Unternehmensdaten** ersetzt werden (Firmenname/Rechtsform, Anschrift,
vertretungsberechtigte Person, RUC/Registernummer, Telefon, Hoster, zuständige Aufsichtsbehörde,
Rechtswahl/Gerichtsstand). Die Texte sind sorgfältige Entwürfe und ersetzen **keine Rechtsberatung** –
bei grenzüberschreitendem Geschäft (Paraguay ↔ EU/DACH) anwaltliche Prüfung empfohlen.
